## 🌍 Multi-Language Support

TrackGuests supports 11 languages:
- **Fully Translated**: English, Spanish, French, German, Italian
- **Template Available**: Portuguese, Japanese, Korean, Chinese, Russian, Arabic

Users can select their preferred language in settings, and the interface will automatically translate.

## 🏗️ System Architecture Overview

### User Roles
- **Visitors**: External guests, clients, deliveries
- **Staff**: Employees, team members, regular users
- **Residents**: Building residents or tenants
- **Administrators**: System managers with full access

### Data Structure
- **Properties/Residences**: Buildings or locations
- **Rooms**: Individual units within properties
- **Persons**: Individual visit records
- **Users**: System accounts with role-based access

### Workflow Overview
1. **Setup**: Admin creates properties and rooms
2. **Access**: Users check in to specific rooms
3. **Tracking**: System records all visit activity
4. **Management**: Admins monitor and export data
5. **Analysis**: Data used for reporting and compliance
